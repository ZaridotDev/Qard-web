# Scope

## MVP
El alcance del MVP incluye:
- Autenticación básica de usuarios.
- Gestión de transacciones: ingresos, egresos, cuotas y compras compuestas (`shopping_items`).
- Gestión de cuentas y métodos de pago (crédito/débito).
- Categorización y presupuestos.
- Dashboard: Balance general, ingresos vs egresos y métricas clave de salud financiera.
- Historial detallado: Visualización global con filtros por transacciones/cuotas/compras.
- **Integración WhatsApp**: Registro de gastos vía chat y notificaciones inteligentes de engagement.

## Out of Scope (Post-MVP)
- Sistema de perfiles "tipo Netflix" (perfiles múltiples, invitados y gastos compartidos).
- IA integrada (Vertex) para recomendaciones activas.
- Módulo de cálculo de inversiones.
- Integraciones Open Banking.

## Restricciones
- El sistema debe mantenerse dentro de las capacidades del stack actual (Supabase + React).
